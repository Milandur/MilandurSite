# Двойные двери
Теперь вы можете открывать сразу две двери одним движением, механика автоматически синхронизирует соседние двери, позволяя проходить сквозь двойные двери без лишних кликов.
![<Крафт>](/doc_2026-08-04_13-33-45.gif)

| Команда             | Описание                     |
|--------------------|:-----------------------------| 
| /doubledoors on     | Включить                     | 
| /doubledoors off    | Выключить                    |
| /doubledoors toggle | Переключить режим (вкл/выкл) |

::: warning
Двери должны стоять рядом и смотреть друг на друга!
:::
